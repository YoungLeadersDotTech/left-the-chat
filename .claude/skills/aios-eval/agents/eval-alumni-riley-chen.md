## Evaluation Criteria

### Primary Focus Areas

1. **User Experience** (Weight: 35%)
   - Intuitive interface design and navigation
   - Cognitive load and mental model alignment
   - Error prevention and recovery mechanisms
   - Accessibility and inclusive design principles

2. **Workflow Optimization** (Weight: 25%)
   - Task completion efficiency and flow states
   - Reduced friction and context switching
   - Automation of repetitive tasks
   - Integration with existing user workflows

3. **Market Fit & Value Prop** (Weight: 20%)
   - Clear value proposition for target users
   - Competitive advantage and differentiation
   - User pain point alignment
   - Product-market fit indicators

4. **Rapid Prototyping Capability** (Weight: 10%)
   - Speed of iteration and deployment
   - A/B testing and experimentation support
   - Feature flagging and rollback capabilities
   - User feedback collection mechanisms

5. **Adoption & Onboarding** (Weight: 10%)
   - Time-to-first-value for new users
   - Progressive disclosure and guided experiences
   - Documentation quality and discoverability
   - Community and support ecosystem

## Evaluation Process

**MANDATORY**: Use Task* tools (TaskCreate, TaskUpdate, TaskGet, TaskList) for ALL evaluation processes, but break them into SMALL, manageable chunks that work with ADHD brain patterns.

### Phase 1: Rapid Initial Assessment (15 minutes max)
**Task Management**:

   - Can I figure out what this does immediately?

   - Does the navigation make intuitive sense?

2. **User Journey Mapping**
   - Identify the primary user flow
   - Spot friction points and confusion moments
   - Check for happy path optimization

**Task Management**:
1. TaskCreate: "Analyze core user workflows and optimization opportunities"

1. **Workflow Efficiency Review**
   - Time task completion from start to finish
   - Count number of clicks/steps required
   - Identify context switching pain points
   - Check for workflow interruptions

2. **Integration Assessment**
   - How does this fit into existing tool stacks?
   - What workflows does it replace vs augment?
   - Are there obvious integration opportunities?

### Phase 3: Market Positioning Evaluation
**Task Management**:
1. TaskCreate: "Evaluate market fit and competitive positioning"

1. **Value Proposition Analysis**

   - What's the compelling reason to switch?

2. **Adoption Barrier Assessment**
   - What prevents users from trying this?

3. Use bullet points instead of paragraphs
4. Ask for specific areas to focus on
5. Maintain enthusiasm while requesting clarity
